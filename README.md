# RC 梁分析設計工具 v1.5

可離線使用的繁體中文 RC 梁斷面分析網頁。直接以瀏覽器開啟 `index.html`，不需要安裝套件或連線。

## 功能

- 調整梁尺寸、材料、載重及多排主筋，即時顯示檢核結果。
- 正負彎矩分析、應變相容法、剪力與箍筋檢核、簡支均布載重撓度分析。
- 圖示各排主筋位置、中心距及淨距。
- 新增同側主筋排時，預設與最內排主筋淨距 2.5 cm；仍依骨材等條件執行淨距檢核。
- 列印計算報告、匯出保留參數的單檔離線網頁。

## 計算範圍

程式依臺灣 112 年版混凝土結構設計規範及 113 年 2 月勘誤建立所涵蓋的檢核。單位為 cm、kgf/cm²、tf、tf·m。適用一般重混凝土矩形、非預力梁；提供直接輸入設計內力與簡支全跨均布載重模式。

頁面列出計算假設、公式與未涵蓋項目。未完整涵蓋耐震細節、錨定搭接、接頭、T 梁、軸力、扭矩及深梁等設計；檢核通過僅代表程式涵蓋項目通過。

## 原始碼與驗證

- `engine.js`：計算核心。
- `ui.js`：參數輸入、結果及圖示。
- `template.html`：頁面樣板與樣式。
- `index.html`：整合完成的網頁及離線版。
- `verify.cjs`：14 組計算驗證。

如需修改原始碼，安裝 Node.js 後執行：

```sh
node verify.cjs
node build.cjs
```

## GitHub Pages

在儲存庫 Settings → Pages 選擇 Deploy from a branch，使用 `main` 分支及根目錄 `/ (root)`。首頁為 `index.html`。

桌面改為固定工具列及獨立捲動工作區，可收合參數面板；手機使用底部四分頁及工具選單，表單與主要操作符合 44 px 觸控尺寸。重新核對官方規範並修正保護層引用條號（20.5.1.3.1），計算數值不變。獨立 Python 驗算的 14 個預設案例數值與網頁相符，14 組原有測試通過。詳見網頁「規範與驗證」。
