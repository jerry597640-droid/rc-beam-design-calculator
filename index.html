01斷面與材料

尺寸：cm；強度：kgf/cm²。矩形、常重、非預力 RC 梁，軸力與扭矩為零。

02載重與分析方向

直接輸入模式：Mu、Vu 應為已考慮載重組合之設計值，取絕對值。本工具不再乘載重因數，且不推算撓度。

03逐層主筋

各排以所選梁面為基準。「內移量 = 0」代表緊鄰箍筋內緣；鋼筋中心距 = 保護層 + 箍筋直徑 + 主筋半徑 + 內移量。

新增排與同側最內排預設淨距 2.5 cm（非中心距）；若粒徑要求較大，檢核仍會提示調整。

配筋設計建議

固定另一側配筋，以 1–3 排、每排 2–12 支搜尋最小面積可行配置。

04箍筋與使用性

箍筋採垂直有效肢、沿梁寬等距。所有案例均要求至少 Av,min；未採小剪力或淺梁豁免。

五步完成一次分析

  1. 在「斷面」輸入尺寸、保護層、骨材及材料參數。
  2. 在「載重」選擇分析模式，確認彎矩方向，輸入跨度／線載重或已因數化 Mu、Vu。
  3. 在「主筋」逐排填入上、下緣配筋；看圖核對位置、排內淨距及排間淨距。
  4. 在「箍筋」輸入號數、肢數、間距與強度；均布模式另填長期撓度條件。
  5. 查看「圖形與結果」，點未通過項目的「前往調整」。在「計算書」檢視公式及代入值；最後列印或下載離線檔。
桌面：左側參數與右側結果各自捲動，可收合參數面板。手機：底部切換「參數／結果／計算書／規範／說明」；右上「工具」提供範例、離線下載與列印。修改參數會立即重新計算；空白或不合理輸入會停止結果顯示。

額外靜載重 Dtf/m；例 1.2未乘載重因數、且不含本梁自重的全跨均布線載重。可包含分攤樓板自重、粉刷、固定隔間及設備；避免與模型自重重複。載重計算書、材料單位重、版厚與梁分攤寬度。面載重 tf/m² × 分攤寬 m = tf/m。

設計彎矩 |Mu|tf·m；例 30直接模式填已因數化之需求彎矩絕對值；正負方向另選。不是容許彎矩，也不是未組合的 MD、ML。ETABS、MIDAS Gen、SAP2000 等結構分析的強度設計組合結果，或核定手算內力。確認梁號、位置、局部軸及單位。
設計剪力 |Vu|tf；例 20直接模式填已因數化的需求剪力絕對值；網頁不再乘 1.2 或 1.6。須檢核所選斷面與適用設計組合／包絡。與 Mu 相應分析模型的剪力結果。包絡最大值可能來自不同組合，應保留各自組合及位置記錄。
