01斷面與材料

尺寸：cm；強度：kgf/cm²。矩形、常重、非預力 RC 梁，軸力與扭矩為零。

02載重與分析方向

直接輸入模式：Mu、Vu 應為已考慮載重組合之設計值，取絕對值。本工具不再乘載重因數，且不推算撓度。

03逐層主筋

各排以所選梁面為基準。「內移量 = 0」代表緊鄰箍筋內緣；鋼筋中心距 = 保護層 + 箍筋直徑 + 主筋半徑 + 內移量。

新增排與同側最內排預設淨距 2.5 cm（非中心距）；若粒徑要求較大，檢核仍會提示調整。

配筋設計建議

固定另一側配筋，以 1–3 排、每排 2–12 支搜尋最小面積可行配置。

04箍筋與使用性

箍筋採垂直有效肢、沿梁寬等距。所有案例均要求至少 Av,min；未採小剪力或淺梁豁免。

壓縮檔中的計算流程與輸入方式

來源：RC_Section_20121009_SourceCode.zip → SourceCode/20121009/RC_Section_Design/FormMain.vb、FormAddRebar.vb。為 Visual Basic Windows Forms 程式；資料夾標示 2012，部分檔案修改至 2016。

  1. 輸入矩形梁寬 b、深 h、保護層 c、f′c、Es、跨度，以及靜載／活載彎矩與剪力。
  2. 逐排建立上下層主筋：鋼筋號數、根數、降伏強度及位置；輸入箍筋號數與降伏強度。網頁版統一各排主筋 fy，保留逐排位置、根數與號數。
  3. CAL_NeutralAxis：以極限壓應變 0.003、β₁ 等值應力塊、鋼筋彈塑性應力，反覆尋找 C = T。
  4. CAL_RC_Section：計算 Mn、φMn、最小鋼筋量、應變與鋼筋淨距。CAL_RC_Design：由需求 Mu 搜尋配筋，再回算斷面。
  5. CAL_Shear：計算 Vc、需求 Vs、箍筋所需間距及上限。
  6. CAL_Checkdeflection：計算 Mcr、Icr、Ie，即時與長期撓度，並輸出報表。

適用範圍及工程上仍需完成的檢核

本工具涵蓋矩形斷面、單軸純彎、一般重力剪力與簡支均布載重撓度；材料範圍 f′c = 210–560、主筋 fy = 2,800–5,600、箍筋 fyt = 2,800–4,200 kgf/cm²。保護層檢核僅採非暴露環境現場澆置梁 4 cm。

未涵蓋第十八章耐震梁端圍束、容量剪力、強柱弱梁、接頭、錨定／搭接／截斷、扭力、軸力、T 梁、深梁與不連續區、開孔、火害或劣化。梁深超過 90 cm 另須檢核側面筋；層間對齊、箍筋彎鉤及受壓鋼筋側向支撐須依圖說檢核。綠色結果僅代表已列計算項目，並非完整規範認證。

均布載重模式僅考慮 D、L 組合 max(1.4D, 1.2D+1.6L)，不含地震、風、土壓等。Vu 採支承反力，未減至離支承面 d 處。跨度輸入應與所採分析模型相符。直接內力模式不推算載重分布或撓度。

長期撓度採 λΔ = ξ/(1+50ρ′)，後續撓度保守取全部依時增量 + 活載即時撓度；未扣除附屬構材安裝前已發生的變形。設計建議為指定號數、固定另一側筋之有限搜尋，不保證全域最省鋼筋。
